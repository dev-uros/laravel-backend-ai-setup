# Scramble

## Keep ApiResponseTypeInfer in sync with ApiResponse
API docs are generated by Scramble from the code — UI at `/docs/api`, spec at `/docs/api.json`. No annotations.

Scramble reads the controller's return statement. `ApiResponse::success(...)` is a static call into another class, and Scramble cannot see through it: without help, every endpoint documents as an empty `object`. `App\Support\Scramble\ApiResponseTypeInfer` (a `StaticMethodReturnTypeExtension`, registered in the `extensions` array of `config/scramble.php`) maps each ApiResponse method to the `{message, data}` shape plus its status code.

Adding a method to `ApiResponse` means adding a case to that extension's `match`, or endpoints using it silently lose their response schema — the docs stay green while going wrong, so nothing fails to warn you.

After changing either class, check the real output rather than trusting it:

    curl -s localhost:8000/docs/api.json | python3 -m json.tool

Resource `toArray()` should return real types (typed return, `->toIso8601String()`); that is what Scramble converts into the component schema. Reach for `?->` only where the value genuinely can be null — it is what puts `null` in the field's documented type, so a null-safe call on a column that is never null documents a nullability no client will ever meet. See the `actor` and timestamp notes in `.ai/rules/http-resources.md`.

## 429 is documented from the route's throttle middleware
Scramble derives error responses from the exceptions a service throws, and the throttle middleware throws before the controller is reached — so a `throttle:` route documented 200/401/422 and stayed silent about 429.

`App\Support\Scramble\ThrottledResponseExtension` (an `OperationExtension`, registered in the same `extensions` array in `config/scramble.php`) reads `throttle:{attempts},{minutes}` off the route and adds the 429 with its body, `Retry-After` / `X-RateLimit-*` headers and the real limit in the description. Adding or removing a `throttle:` on a route now updates the document by itself — do not annotate actions by hand.

That array takes both infer extensions and operation extensions; Scramble filters by base class. Operation extensions from config run *after* `ResponseExtension`, which is why this one adds a `Response` directly instead of attaching an exception to the method type — that would be too late to have any effect.

`tests/Feature/Docs/OpenApiSpecTest.php` asserts the real 429 matches, with `app.debug` forced off (debug adds `exception`/`file`/`line`/`trace` to every rendered error).
